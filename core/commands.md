# ⚡ Comandos de Performance Agent Skill (`performance-agent-skill`)

| Comando | Acción | Descripción |
|---|---|---|
| `$performance` | Bootstrap | Bootstrap de la habilidad de rendimiento, memoria y perfilado. |
| `$performance:audit` | Auditoría Global | Auditoría integral multi-vector (CPU, Memoria, Render, Bundle, Startup). |
| `$performance:mobile` | Perfil Móvil | Auditoría consolidada para aplicaciones móviles (Frame Budget, Batería, Memoria). |
| `$performance:flutter` | Adaptador Flutter | Perfilado específico con DevTools, RepaintBoundary y render tree. |
| `$performance:android` | Adaptador Android | Perfilado con GPU Rendering, Baseline Profiles y Memory Profiler. |
| `$performance:ios` | Adaptador iOS | Perfilado con Instruments, Time Profiler, Leaks y Memory Graph. |
| `$performance:web` | Adaptador Web | Perfilado de Core Web Vitals (LCP, INP, CLS), Long Tasks y bundles. |
| `$performance:backend` | Adaptador Backend | Perfilado de latencia p95/p99, throughput, queries N+1 y connection pool. |
| `$learnskill performance-agent-skill [propuesta]` | Aprendizaje | Registrar propuesta de mejora para la skill en `overview/learning.md`. |
| `$revlearnskill` | Revisión | Inspeccionar y promover propuestas de aprendizaje de la skill. |
